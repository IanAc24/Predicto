# Predicto

Personal app that follows a watchlist of stocks (e.g. Nike, Adidas), observes them for weeks,
then shows a calibrated probability that each will be up over the next 5 trading days.
Plan and work packages: `docs/Stock prediction app build plan.md`.

## Layout

- `apps/web` - Vite + React + TypeScript SPA (TanStack Router file routes in `src/routes`, TanStack Query, Tailwind v4)
  - `src/ui` shared components (Tailwind + design tokens in `index.css`), `src/ui/shell` app bar and layout; `src/api` domain types, TanStack Query hooks and the mock backend (`src/api/mock`); `src/i18n` en/es dictionaries, one file per namespace (`useT()`); `src/settings` language and theme; `src/lib` formatters; `src/features` one folder per screen (empty for now)
  - Mock scenarios: add `?scenario=default|empty|observing|stale|error` to the URL (read once at startup)
- `packages/` - shared packages (generated API client will live in `packages/api-client`)
- `contracts/` - hand-authored OpenAPI contract (source of truth for the API)
- `docs/` - build plan and research notes

Python backend and ML pipeline (FastAPI, uv) arrive in Phase 2; Python and uv are not installed yet.

## Commands (run from repo root, PowerShell or Git Bash)

- `pnpm install` - install dependencies
- `pnpm dev` - start the web app
- `pnpm build` - type-check and build
- `pnpm test` - run Vitest
- `pnpm lint` - run oxlint
- `pnpm typecheck` - run tsc
- `pnpm e2e` - run Playwright smoke and accessibility tests (Chromium; starts its own Vite server on port 5183; first time: `pnpm --filter web exec playwright install chromium`)

All of build, test, lint and typecheck must pass (and e2e when UI behaviour changes) before a work package is done.

## Rules

- Do not hand-edit generated files: `apps/web/src/routeTree.gen.ts` (regenerated by the Vite plugin; commit it) and anything under `packages/api-client/src/generated`.
- Never use imperative "buy" or "sell" wording in the UI. Show probabilities with base rate and sample size.
- Decided: personal use only, 5-trading-day horizon, runs locally on Windows.
